01这套教程解决什么

一句话：会思考的调度员 + 会动手的工人，各自装到你电脑上。

模块一 Harness（以 DSH 为例） ← 会思考的调度员
"让 AI 能真的操作你这台电脑"
↓ 用 HTTP 打通
模块二 视频生成平台（ComfyUI / LibTV） ← 会动手的工人
"让画面和声音真的生成出来"
↓
已有教程《AI短片工作流教程》：分镜 → 提示词 → 出片

模块一 · Harness Harness 是什么 → 装 DSH → 接模型 → 跑通第一个任务 → 以后遇到问题怎么指挥它自己排查。

模块二 · 视频平台 云端还是本地 → 装 ComfyUI → 模型放哪 → 跑出第一张图 → 接上 H3 出带声音的视频 → 工作流与云端配合。

两个模块都是 0–5 六节第 0 节只讲"这是什么、为什么"，不装任何东西；第 1–5 节一步一节，每节结尾有一个验收。

03模块一 · Harness（以 DSH 为例）

完整正文见 01_Harness_DSH.md。这里是路线图。

0

harness 是什么 三层关系：模型（会思考，但被关在盒子里）→ harness（给它装上手、记忆、约束、调度）→ 应用（桌面端 / 浏览器界面）。模型是发动机，harness 是整台车。

1

装之前准备两样东西 Node.js（nodejs.org 下 LTS 版）＋ 一个 DeepSeek API Key（platform.deepseek.com）。装完用 node -v 和 npm -v 验证。

2

三种装法，新手选第一种 A 桌面端（官网下载安装包，不需要命令行，推荐）／ B 命令行 npx（npx @deepseek-ai/dsh web）／ C 源码运行（要改代码才用）。

3

第一次启动与接入模型 浏览器打开 http://127.0.0.1:3080 → 设置 → 模型 → 粘贴 API Key 保存。保存后立刻生效，不用重启。

4

跑通第一个任务（这里有个必踩的坑） 全新的网页界面没有选中工作区时，输入框是灰的、点不动——不是软件坏了。先「选择工作区」添加一个文件夹并选中它。

5

以后遇到问题怎么办（本模块重点） 不要自己百度报错，把报错原样丢给 DSH。这一节给了 5 个可直接复制的提问模板和三条提问纪律。

鲸鱼娘

第 4 节那个灰输入框的坑，我见一个劝一个：装完先别急着问问题，先把工作区选中。输入框点不动不是你装坏了，是我还没被告诉"在哪个文件夹里干活"。

必须记住的一条

权限三档，用大白话记：

档位能做什么什么时候用
read-only只看不改最安全，先用它熟悉
workspace-write能改工作区里的文件日常干活用这个
danger-full-access全盘可动全自动时才用，要知道风险
DSH 处于开发者预览阶段，官方明确说会有破坏兼容性的变更。装之前先打开官方快速开始页面对一眼，别照着半年前的截图装。

04模块二 · 视频生成平台（ComfyUI / LibTV）

完整正文见 02_视频平台_ComfyUI与LibTV.md。这里是路线图。

0

两类平台，不是二选一 云端（LibTV 这类，打开网页就用、按积分付费、模型最新）／ 本地（ComfyUI，跑在自己显卡上、无限出片、数据不出本机）。本地跑量和控细节，云端追新模型出单条。

1

先看你有没有这块显卡 这是唯一可能直接劝退的一节。显存 8G 以下或只有核显，先用云端平台，不要硬上本地。

2

把 ComfyUI 装到电脑上 A 桌面版（推荐新手，自动管 Python）／ B 便携版（Windows 解压即用，整个文件夹能搬走）／ C 源码（不展开）。启动后访问 http://127.0.0.1:8188。

3

装模型，跑出第一张图 模型按类别放目录（checkpoints / diffusion_models / text_encoders / vae / loras），放完刷新界面才能在下拉框里看到。

4

接上视频生成（MiniMax H3 本地版） ComfyUI 0.30.0+ 的模板库里选 MiniMax H3；Ref2VA / I2VA / FL2VA 三种模式对应不同镜头；权重两个文件不通用。

5

工作流怎么用，云端怎么配合 把网盘里的 .json 直接拖进 ComfyUI 窗口就能还原整张图；LibTV 负责创意验证和最新模型，ComfyUI 负责批量与一致性。

模型放哪（最容易出错的一张表）

类型目录（相对 ComfyUI 根目录）用来做什么
大模型 / 检查点models/checkpoints/出图的主模型
视频扩散模型models/diffusion_models/视频生成的主模型
文本编码器models/text_encoders/把提示词翻译成模型能懂的东西
VAEmodels/vae/决定画面色彩与解码质量
LoRAmodels/loras/风格微调或加速
自定义节点custom_nodes/装扩展功能
工作流 .json不用放目录直接拖进 ComfyUI 界面

两个容易漏的细节：视频 VAE 有 int8 量化版和 fp16 全精度版两套，显存紧张（8G 卡）优先用 int8，16G 以上用 fp16 画质更好；Turbo LoRA 放 models/loras/，用来 8 步出小样，别用正式步数去试构图。

下载走国内镜像更快：模型发布在 Comfy-Org/MiniMax-H3 仓库，把地址里的 huggingface.co 换成 hf-mirror.com 即可。光文本编码器一个文件就 15.7 GB，下载慢是正常的，断了续传。

时长不是整数（排分镜前必须知道）

视频时长会吸附到一个固定帧网格，请求 4 秒实际得到的是 3.75 秒或 4.46 秒：

你请求实际帧数实际时长
4s90 或 1073.75s 或 4.46s
5s1245.17s
6s1415.88s
8s1928.00s

把分镜表加起来时一定要留余量，否则最后一定超时。

鲸鱼娘

关于 LibTV 我要认真说一句：它没有"本地部署版"。它是纯云端平台，网页版 + 微软商店的 Windows 客户端。网上那些"LibTV 本地部署 / 满血破解版"，来路不明、有安全风险，也违反服务条款——别装。想本地化就用 ComfyUI，这是两回事。

05三条验收线

全做完的标准不是"看完了"，是这三条都能做到。

✓

模块一 我能让 DSH 读到我指定文件夹里的文件，并让它帮我改一个文件。

✓

模块二（出图） 我能用 ComfyUI 出一张图，并保存一份工作流。

✓

模块二（出视频） 我能跑出一条 4 秒左右、带声音的视频片段。

三条都过了，就可以进《AI短片工作流教程》，开始做真正的片子了。

遇到问题的三条纪律

  1. 报错贴原文，不要转述成"它说错了"；
