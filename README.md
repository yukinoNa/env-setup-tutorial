# 环境搭建教程 · 把 AI 短片生产线装到自己电脑上

> 这是《AI短片工作流教程》的**前置章**。
> 那边讲的是"怎么拍这支片子"，这边讲的是"**怎么把工具装到你自己的电脑上**"。
> 两份都读完，你才算具备独立开工的条件。

---

## 一、这份教程在讲什么

一句话：**会思考的调度员 + 会动手的工人，各自装到你电脑上。**

```
模块一  Harness（以 DSH 为例）      ← 会思考的调度员
        "让 AI 能真的操作你这台电脑"
             ↓ 用 HTTP 打通
模块二  视频生成平台（ComfyUI / LibTV） ← 会动手的工人
        "让画面和声音真的生成出来"
             ↓
已有教程《AI短片工作流教程》：分镜 → 提示词 → 出片
```

两个模块都是 **0–5 六节**：第 0 节只讲"这是什么、为什么"，不装任何东西；第 1–5 节一步一节，每节结尾有一个验收。

**看到「✅ 验收」就停下来，做一遍再往下走。** 跳过验收往下赶，是新手最常翻车的方式。

## 二、两个模块分别讲什么

| 模块 | 文件 | 讲什么 | 学完能干什么 |
|---|---|---|---|
| **模块一** | `01_Harness_DSH.md` | Harness 是什么；怎么在自己电脑上装好 DeepSeek Harness（DSH）；怎么接模型；怎么跑通第一个任务；**以后遇到问题怎么指挥它自己排查** | 有一个能读写你文件、能跑命令、能联网查资料的 AI 助手 |

**网页版**：`index.html`，双击用浏览器打开，适合通读和转发给组员。

## 四、开工前先备齐这些

### 硬件

| 项 | 要求 | 说明 |
|---|---|---|
| 系统 | Windows 10 / 11（推荐）或 macOS | ComfyUI 三平台都有，但**视频生成基本只认 NVIDIA 显卡** |
| 显卡 | **NVIDIA 独显，显存 8G 起** | 12–16G 舒服，24G 才谈得上顺畅。**显存 8G 以下或只有核显的，本地方案先放一放，直接用云端平台** |
| 内存 | 16G 起，32G 更稳 | |
| 硬盘 | **留 100G 以上空间** | 模型文件一个就几十 G |
| 网络 | 能正常访问 GitHub 与各模型下载源 | 下载模型是最耗时的一步，建议挂机下 |

**不知道自己显卡是什么？** 任务管理器 → 性能 → GPU，看型号和"专用 GPU 内存"。或者直接把这个问题丢给 DSH：「我的显卡是 XXX，显存 XXG，能跑 ComfyUI 吗」

## 五、网盘素材（模型与工作流）

**ComfyUI 本身不含任何模型**，它只是一张画布。本教程配套的模型文件和工作流文件统一放在网盘：

> **https://pan.quark.cn/s/b56c72da3ce4（49 个文件 / 126.8 GB）**

下载后按 `02_视频平台_ComfyUI与LibTV.md` 第 3 节的表格，逐个放进对应目录。**放错目录是新手第一大坑**——文件放对了但在界面里找不到，八成是放错了文件夹。

| 素材 | 大概放在哪 |
|---|---|
| 出图主模型 | `models/checkpoints/` |
| 视频生成主模型 | `models/diffusion_models/` |
| 文本编码器 | `models/text_encoders/` |
| VAE | `models/vae/` |
| 工作流文件（`.json`） | 不用放目录，**直接拖进 ComfyUI 界面** |

## 六、三条验收线

全做完的标准不是"看完了"，是**这三条都能做到**：

- [ ] **模块一**：我能让 DSH 读到我指定文件夹里的文件，并让它帮我改一个文件
- [ ] **模块二（出图）**：我能用 ComfyUI 出一张图，并保存一份工作流
- [ ] **模块二（出视频）**：我能跑出一条 4 秒左右、**带声音**的视频片段

三条都过了，就可以进《AI短片工作流教程》，开始做真正的片子了。

## 七、遇到问题怎么办（先看这条，再动手）

**不要自己百度报错。** 把报错原样丢给 DSH，让它查。

三条提问纪律：

1. **报错贴原文**，不要转述成"它说错了"；
2. **说清你想要什么结果**，别只说哪里不对；
3. **一次只解决一个问题**，别把三件事塞进一句话。

具体提问模板见 `01_Harness_DSH.md` 第 5 节。

## 八、关于版本（必读）

- **DSH 处于开发者预览（Developer Preview）阶段**，官方明确说会有破坏兼容性的变更。教程里的操作方式以你安装时的官方文档为准，**装之前先打开官方快速开始页面对一眼**。
- **ComfyUI 迭代很快**，界面按钮位置和菜单措辞可能和你看到的不一样，以官方中文文档为准。
- 两个工具的官方文档入口都写在各自文件末尾的「速查卡」里，**那个速查卡比百度有用**。
